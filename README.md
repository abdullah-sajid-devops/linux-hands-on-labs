# 🧪 Linux Hands-On Labs

Practical, project-based labs built while working through my [Linux SysAdmin Journey](https://github.com/abdullah-sajid-devops/linux-sysadmin-journey) — this repo is where daily learning gets applied to real, hands-on exercises instead of just staying in notes.

Each lab combines concepts from multiple chapters/days into a single practical scenario, tested live on an AWS EC2 instance.

---

## 🎯 Purpose

- Turn theory into muscle memory
- Consolidate learning across multiple days/chapters into one practical task
- Build a portfolio of real, demonstrable Linux skills — not just certificates

---

## 🧰 Environment

- **OS**: Ubuntu Server (AWS EC2)
- **Shell**: Bash
- **Source**: Concepts from Cisco Networking Academy — Linux Essentials

---

## 📂 Labs

| Lab | Title | Concepts Covered |
|---|---|---|
| 01 | [System Health Monitor](lab-01-system-health-monitor/) | Command substitution, `awk`/`sed` text extraction, disk/memory monitoring, `if/else` conditional logic |
| 02 | [Log Analyzer](lab-02-log-analyzer/) | `grep` pattern matching, `wc -l` counting, `if/else` conditional logic |
